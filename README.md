# Arabesque – scénarios de cloisonnement

- `index.html` : outil web autonome pour tester des cloisonnements sur le RDC et l'étage (cloisons, portes, meubles, contrôles de surfaces et de passages, métré et budget, export PNG / DXF). Ouvrir le fichier dans un navigateur.
- `maquette_rdc_etage.rb` : script SketchUp (Pro ou Make 2017) qui construit la maquette 3D des deux niveaux. Console Ruby : `load "chemin/maquette_rdc_etage.rb"`.

Cotes reprises des plans ; épaisseurs, profondeur hors œuvre et allèges non cotées sont estimées, à vérifier sur site.
